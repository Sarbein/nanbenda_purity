# nanbenda_purity

A purity system web application for managing rice inventory by Nanbenda Barters LLC.

## Features

- Dashboard: Overview of inventory and operations
- Products & Pricing: Manage product catalog and pricing
- Sales: Track sales transactions
- WhatsApp Logs: View communication logs
- Finance / Invoicing: Handle financial records and invoices
- Reports: Generate various reports
- AI Assistant: Integrated AI for assistance

## How to Run

Simply open `index.html` in a web browser. The application uses local storage for data persistence.

## Technologies Used

- HTML5
- Tailwind CSS for styling
- Material Symbols for icons
- Custom JavaScript for functionality
- Google Fonts (Manrope, Inter, Public Sans)

## Development

This is a static web application. No build process is required. Edit the HTML, CSS, and JavaScript directly in `index.html`.
